# 3D-Console-Game

## What is this?
This is a 3D game I developed that has a cpu rasterizer which runs in a console/terminal window. It is currently only compatible with windows unfortunately, however it has a physics engine, has enemies with behaviors, and a basic particle system. It takes mouse inputs, wasd, has hud element support which can use mouse input to physically click on buttons, and has various items the player can hold and use.
