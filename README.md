## What is this?
This is a 3D game I developed that has a cpu rasterizer which runs in a console/terminal window. It is currently only compatible with windows unfortunately cause I didn't wanna do p/invokes for mac bindings, however it has a physics engine, has enemies with behaviors, and a basic particle system. It takes mouse inputs, wasd, has hud element support which can use mouse input to physically click on buttons, and has various items the player can hold and use. I'm quite happy with how it turned out and it has quite fun player movement and you get a grappling hook and guns which are pretty cool, and the aesthetic of the engine actually kinda works ok which is cool. I found it quite fun to develop an 'engine' of sorts from scratch cause it gave me a lot of control over how things should work and let me make some fun design decisions. Could work on in the future to turn into a playable demo, but for now it'll just stay as a learning experiment that was surprisingly successful and fun.
